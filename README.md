# Habib Ur Rehman

ML/AI Engineer and healthcare-AI researcher. I build machine learning that earns trust — medical imaging, deepfake detection, and multimodal intelligence.

**What I build** (all open source, all measured):

- [monitor-canary](https://github.com/habib-analyst/monitor-canary) — canary-contract protocol that tests whether safety monitors actually catch what they claim to catch (95.83% harness accuracy, deterministic, zero LLMs)
- [sai-authority-injection](https://github.com/habib-analyst/sai-authority-injection) — typed, schema-validated MCP overrides that keep human control over agents persistent (100% compliance across 2,400 episodes, while free-text overrides eroded after 2 turns)
- [verirag](https://github.com/habib-analyst/verirag) — RAG that retrieves when it should and refuses when it must: 6-signal refusal layer (adversarial refusal 10/20 at 91% precision, naive RAG 0/20)
- [clausebench](https://github.com/habib-analyst/clausebench) — AI-in-law benchmark: contract-clause extraction over 13,823 CUAD spans (accuracy 0.7222, macro-F1 0.5046)
- [surgwatch](https://github.com/habib-analyst/surgwatch) — first open implementation of SurgStreamer event semantics for surgical video, with a live demo on Hugging Face
- [agentplan](https://github.com/habib-analyst/agentplan) — cost-based query planner for agent orchestration (token use cut to 71.9%, wall-clock down 84–96%)
- [beliefcollapse](https://github.com/habib-analyst/beliefcollapse) — measures when multi-agent debate contaminates what agents privately believe, not just what they publicly say
- [rag-shield](https://github.com/habib-analyst/rag-shield) — offline prompt-injection / poisoned-document detector for RAG corpora (stdlib-only; 16/16 synthetic attacks caught, 0 false flags on benign docs)
- [desync-detect](https://github.com/habib-analyst/desync-detect) — CPU-only audio-video desynchronization detector for deepfake triage
- [veriproof](https://github.com/habib-analyst/veriproof) — tamper-evident forensic verification: forged-screenshot benchmark, detector, and signed evidence reports
- [GCViT–PIO Medical Imaging](https://github.com/habib-analyst/GCViT-PIO-Medical-Imaging) — hybrid vision transformer + Perceiver IO multi-disease classification (brain/lung/skin; paper: *Journal of Supercomputing*, 2025)
- [ViT + Perceiver IO Framework](https://github.com/habib-analyst/ViT-PiO-Framework-For-Medical-Imaging) — multi-disease medical image classifiers (paper: *Computational Biology and Chemistry* 119, 2025)
- [MedMNIST v2 Reproducibility Benchmark](https://github.com/habib-analyst/MedMNIST_v2_Reproducibility_Benchmark) — reproducible deep-learning benchmarking across MedMNIST v2
